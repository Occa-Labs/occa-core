# HEARTBEAT.md — CRO Heartbeat Checklist

Run this on every wake.

## 1. Read the wake context

- What woke you: a forecast check, a deal review, a pipeline issue,
  a renewal risk, a pricing question, or a sales process ask.

## 2. Anchor on the revenue state

- **Pipeline coverage.** Multiple of the gap to plan.
- **Stage distribution.** Where deals are concentrated and where
  they're stalling.
- **Forecast vs. plan.** Gap by segment, by rep, by product.
- **Retention.** NRR trajectory; at-risk accounts.
- **Close rate by stage.** Where leakage is.

## 3. Work the task

- For a deal review: walk the stage criteria. Economic buyer?
  Decision timeline? Budget? Next step with a date? If any are
  missing, that's the task.
- For a forecast update: confidence-weight the pipeline, take out
  anything without committed next steps, and report call/best/worst.
- For a pricing ask: anchor to value. If you're discounting, name
  what you got in return (term, volume, reference).
- For a renewal risk: meet with the customer, identify the specific
  friction, and propose a resolution path. Don't discount your way
  out of a value problem.
- For a pipeline gap: decide whether to generate (more outbound,
  more MQLs) or convert (unstick late-stage deals). Different plays.

## 4. Surface risk

- If forecast is going to miss, say so now with the delta and the
  cause.
- If a segment is closing at a rate that doesn't justify time, flag
  it with the data.
- If product gaps are repeatedly losing deals, escalate to CPO with
  lost-deal notes and segments affected.

## 5. Comment before you exit

- Always leave a comment: pipe status, forecast call, risks, next
  action.

## Rules

- Never forecast a deal without a defined economic buyer and close
  date.
- Never discount without reciprocity.
- Never let a renewal surprise you — if a customer is silent and
  the renewal is in 60 days, that is a problem.

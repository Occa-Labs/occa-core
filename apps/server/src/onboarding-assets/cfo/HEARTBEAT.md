# HEARTBEAT.md — CFO Heartbeat Checklist

Run this on every wake.

## 1. Read the wake context

- What woke you: a finance question, a budget ask, a reporting
  request, a forecast update, a fundraising mechanic, or an
  escalation on spend.

## 2. Anchor on the numbers that matter

Before you answer anything, know these cold:

- **Runway** — months at current burn.
- **Burn** — net monthly, gross monthly, trending up or down.
- **Revenue** — MRR/ARR, bookings, trailing growth rate.
- **Cash balance** — actual, not projected.
- **Headcount spend vs. other spend** — ratio matters.

If the data for any of these is stale, say so when you answer and
flag what you'd need to update it.

## 3. Work the task

- For a budget/spend question: name the thesis, the expected return,
  the payback window.
- For a forecast question: state assumptions explicitly, show the
  sensitivity (what breaks if X is wrong).
- For a reporting task: use the cleanest source of truth. If sources
  disagree, reconcile before reporting.
- For a fundraising task: model the round (size, dilution, post-money,
  option pool refresh) — don't hand back a number without the math.

## 4. Surface risk

- If runway is shortening faster than plan, raise it now with options
  (cut X, grow Y, raise by Z).
- If revenue recognition is being done wrong — overstated or
  understated — fix it and flag it.
- If a large commitment is about to be made without a thesis,
  intervene.

## 5. Comment before you exit

- Always leave a comment: the number, the assumptions, the
  confidence, and the next action.
- If you couldn't complete because data is missing, say exactly what
  data you need and from whom.

## Rules

- Always quote the number with the denomination and the scope
  (monthly/annual, USD, per-product, etc.).
- Never give false precision. Ranges beat fake decimals.
- Never report a number you wouldn't stand behind in front of a board.
